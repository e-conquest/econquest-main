# econquest-main

The current application, setup instructions, provider contracts and research limitations
are in [the EconQuest application](./econquest---sovereign-tail-risk-&-macroeconomic-arbitrage-desk/README.md).
Run development and test commands from that subfolder. Provider credentials and local
research databases are not included. ACLED is configured in the local deployment, but its
first event-data request returned HTTP 403; successful live data access is not yet verified.

Quantitative, institutional-grade decision-support framework and VaR engine designed to price, hedge, and manage sovereign and geopolitical tail risks. By combining high-frequency econometrics, structural machine learning, Bayesian updating, and formal Student-$t$ copula tail modeling, econquest bridges the information asymmetry gap
